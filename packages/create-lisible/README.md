# create-lisible

Companion package of [`lisible`](https://www.npmjs.com/package/lisible) enabling the `create` convention:

```bash
bun create lisible my-blog
npm create lisible@latest my-blog
```

See the [lisible package](https://www.npmjs.com/package/lisible) and the [Lisible framework](https://github.com/didntchooseaname/lisible) for details. Documentation and live previews: [lisible.xsec.fr](https://lisible.xsec.fr)
